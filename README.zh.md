# MCP 控制台

一个设置页：显示当前 profile 里所有 MCP 服务器的实时状态，并在连接变化时
自行更新，同时可以在同一页编辑管理器的 `servers` 配置。

## 安装

DeepSeek Harness 桌面版，**设置 → 插件 → 添加插件**，填入以下之一：

- `github:DongHa0/dsh-mcp` —— 安装本仓库最新提交；
- 本目录检出副本的绝对路径；
- 打包好的 `.tgz` 绝对路径。

装完刷新页面，再打开 **设置 → MCP**。GitHub 方式更新时要先移除再添加；
`npm` 方式有版本列表与一键更新（见 [PUBLISH.md](PUBLISH.md)）。

## 在哪里

打开 **设置 → MCP**（侧栏底部的齿轮）。页面渲染在设置面板里，与「模型」「插件」
「Agent 预设」并列。

## 显示什么

- 每台受管服务器一行，配置条目排在插件注册条目之前。
- 状态圆点与文案：已连接、连接中、重连中、等待凭据、已停用、已关闭，以及失败
  （加载失败 / 清理失败 / 重连次数耗尽 / 已断开 / 未确认关闭）。
- 辅助信息：工具数量与连接时间、当前重试次数与下次重试时间，或最近的诊断文本。
- 「探测」用一次性实例做连通测试，返回服务器标识、对外声明的工具名、耗时以及
  传输是否已关闭。探测期间现有实例照常运行，已停用的条目同样可以探测。
- 「重启」销毁现有实例并以新的重连预算重新挂载，用于重连次数耗尽后的恢复。

## 新增与修改服务器

「添加服务器」与每行的「编辑」打开同一个表单：

- **名称**：`servers` 的键，同时是 `mcp__<名称>__*` 工具命名空间。允许字母、
  数字、下划线或短横，最长 32 个字符；创建后不能改名。
- **传输方式**：`stdio`（启动命令、参数、环境变量、工作目录）或
  `streamable-http`（服务地址、请求头）。
- **启用**：停用后保留配置，但不启动实例。
- **高级**：启动 / 工具调用 / 关闭超时（毫秒），留空则继承管理器与客户端默认值。

「保存」会向 `mcp-manager` 条目的 `servers` 写入一条路径操作，写入经过 profile
的配置文档，并携带本页读到的 revision：期间别处改过配置会被拒绝而不是覆盖，
本页会同步最新值、保留草稿并提示再次保存。
宿主自己的校验信息（缺少启动命令、跨传输字段、重名、`${credential:...}` 模板写错）
会直接显示在表单里；键值行的空键、重复键与非正整数超时在保存前就被拦住。
值支持 `${credential:名称}`，密钥可以留在凭据库而不进配置文件。

「删除」移除本页写入的条目；若该条目同时存在于更下层配置，按钮会变成
「恢复继承」，只删掉用户层覆盖，让继承的服务器回来。

### 快速填表

- 「粘贴配置」接受一个服务器条目、只含一台服务器的 `mcpServers` 片段，或
  `{ "名称": 条目 }`；整表替换，并列出被忽略的键。「撤销」可回到粘贴前的表单。
- 启动命令旁的「从命令行填充」接受 `npx -y @scope/server --flag "a b"` 这类整行
  命令，自动填好命令与参数行；引号/转义按 shell 规则处理，`"C:\nvm4w\nodejs\node.exe"`
  这类 Windows 路径原样保留。
- 参数一行一个：在某一参数行粘贴多行会拆成多行；「批量粘贴」还接受 JSON 数组、
  整条命令行或每行一个参数。
- 环境变量 / 请求头：在任意「键」输入框粘贴 `KEY=VALUE` 多行或一个 JSON 对象，
  会自动展开成多行；`隐藏/显示` 可遮蔽 token 类值，`${}` 按钮插入
  `${credential:}` 并把光标放进花括号里。

其他插件注册的服务器（带「插件注册」徽章）在本页只读，生命周期由注册它的插件拥有。

## 说明

- 本页读取的配置文档与内置配置表单是同一份，任一处修改都会同步到另一处。
- 只读 profile（`writable: false`）会隐藏全部写入控件并给出提示。
- 已移除但清理未完成或失败的条目会以 `configured: false` 继续列出，待清理成功
  或宿主重启后消失。
- 由 agent preset 或静态 `cordis.yml` 挂载、不受管理器治理的 MCP 实例不会列出，
  管理器只治理全局面。
